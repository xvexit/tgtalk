# Журнал решений

| # | Решение | Почему |
|---|---|---|
| 1 | Использовать Telegram Business «Чат-боты» (Автоматизация чатов) | Единственный официальный способ писать от имени пользователя |
| 2 | RAG + профиль стиля вместо файнтюна | Дешевле, данные дозагружаются без переобучения, можно менять модель |
| 3 | Python 3.12, aiogram 3 | Экосистема данных/ML, поддержка Business API, скорость итераций; узкое место — сеть, а не CPU |
| 4 | PostgreSQL 16 + pgvector | Одна БД для сообщений, конфигов, логов и векторов; нет отдельной векторной БД |
| 5 | Всё в Docker Compose | Воспроизводимость, лёгкий перенос на VPS |
| 6 | Long polling, не webhook | Не нужны домен и порты; проще локально |
| 7 | LLM: DeepSeek через OpenAI-совместимый API | Есть ключ; провайдер заменяем через интерфейс |
| 8 | Эмбеддинги локально | У DeepSeek нет эндпоинта эмбеддингов; данные переписок не уходят наружу лишний раз |
| 9 | Dry-run по умолчанию (`SEND_ENABLED=false`) | Нельзя случайно написать живым людям |
| 10 | Оценочный стенд до RAG | Улучшения должны измеряться, а не оцениваться на глаз |
| 11 | Поведение по контактам хранится в БД | Масштабирование без правок кода |
| 12 | Архитектурные решения принимаются в обсуждении, агент в OpenCode только исполняет | Контроль качества и единая архитектура |
| 13 | Охват чатов задаётся настройкой «Автоматизация чатов» в Телеграме; `SEND_ENABLED` — только общий выключатель отправки | Список чатов не дублируется в коде и в БД, один источник правды |
| 14 | Блокировка по чату (`asyncio.Lock`) вокруг пайплайна и отправки | Эхо собственного ответа не должно обгонять запись `role=bot` и провоцировать повторный ответ |
| 15 | История чата уходит на API DeepSeek в промпте | Так работает LLM: контекст передаётся в запросе; эмбеддинги при этом остаются локальными |

## D-00X: Роль сообщения в БД
Решили использовать `TEXT` с `CHECK (role IN ('them','owner','bot'))` вместо Postgres `ENUM`. Меньше миграционных сложностей, проще в расширении.

## D-00Y: Обработка ошибок шагов
При ошибке шага бот молчит (fail-closed).
